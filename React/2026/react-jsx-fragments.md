# JSX — what it compiles to, why you can't return multiple root elements, Tell me about Fragments
- JSX is a syntax extension for JavaScript that lets us write HTML-like code inside JavaScript. Browsers don't understand JSX directly, so tools like Babel or TypeScript compile it into JavaScript. In older React versions, JSX compiled to `React.createElement()` calls, while modern React uses the JSX runtime from `react/jsx-runtime`. These calls create React elements, which are plain JavaScript objects describing the UI—not actual DOM nodes.

- A React component must return a single root React element because a JavaScript function can return only one value. If we need to render multiple sibling elements, we wrap them in a parent element or, preferably, a Fragment. A Fragment groups multiple children without creating an extra DOM node, helping keep the DOM cleaner and avoiding layout or semantic issues. The shorthand syntax <>...</> is commonly used, while React.Fragment is required when the Fragment needs a key, such as when rendering lists.
